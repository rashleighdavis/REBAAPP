# 🚀 REBA - QUICK START GUIDE

## Fastest Way to Deploy (2 Minutes!)

### Option 1: One-Click Script (Easiest)

**Windows Users:**
1. Double-click `quick-deploy.bat`
2. Choose Vercel (option 1)
3. Done! You'll get a live URL

**Mac/Linux Users:**
1. Open Terminal in this folder
2. Run: `./quick-deploy.sh`
3. Choose Vercel (option 1)
4. Done! You'll get a live URL

---

### Option 2: Manual Deploy (3 Steps)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Build the app:**
   ```bash
   npm run build
   ```

3. **Deploy to Vercel:**
   ```bash
   npx vercel
   ```
   
   OR drag the `dist` folder to: https://app.netlify.com/drop

---
